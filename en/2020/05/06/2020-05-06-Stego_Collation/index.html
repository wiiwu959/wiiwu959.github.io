The Ninjutsu of Steganography

As a CTF noob, I can only start with misc challenges that other people might not even bother with and see whether I can pick up a few points. Recently, I thought I should become more familiar with the various Stego tricks so that the next time I try to pick up points, I at least won’t be unable to solve even the misc challenges. So I read some articles about Stego techniques and have organized them here briefly.

Hiding Files

This should be a relatively easy trick to discover: hide a file inside an image. The principle is that image-reading tools usually treat a file as a jpg when they encounter the ending 'FF D9', so they ignore any data after it. The image can therefore still be displayed normally, and changing the file extension to zip turns it back into an archive. I just thought it was interesting, so I am recording it here.

On Windows, you can create one directly with copy /b a.jpg+b.zip output.jpg; on Linux, you can use cat a.jpg b.zip > output.jpg.
When you encounter this, simply opening it with winhex will reveal that there is more data at the end. It can also be easily detected with binwalk.

If you need to extract the hidden content, or split apart content combined in the same file, there are several ways to do so.

  • In winhex, select the part you want to extract, then right-click and choose Edit->Copy Block->Into New File

LSB (Least Significant Bit)

Messages can be hidden in image data. I have encountered this in CTFs, and usually solve it directly with stegsolve. Each pixel consists of three primary colors, and each color uses 8 bits. If only the last bit is changed, it is usually difficult to notice, so a message can be hidden in the last bit. ASCII can be used, or only this one bit can be used to form different patterns and hide a message. This technique cannot be used with jpg because jpg compresses images, which may destroy the hidden message. PNG and BMP images may use this technique.
As an aside, when you encounter a QR code or barcode, you can scan it using this website.

File Repair

Sometimes the provided image is corrupted and needs to be repaired. In such cases, it is helpful to know a little about the structure of different file types, although often only the beginning is incorrect and it can simply be fixed with an editor.
Sometimes the image’s width and height need to be changed. Making them larger may reveal the hidden part.

Metadata

Sometimes a message is hidden directly in an image’s metadata. On Windows, you can view it directly by right-clicking and opening the properties. On Linux, you can use exiftool to inspect it, or upload it directly to an online service.
For example, picoCTF 2018’s Truly an Artist.

Two Images

When two images are provided, you usually need to compare the differences between them. The operation may be XOR/SUB/AND/OR/MUL or something else. You can make use of stegsolve’s Analysis->Image Combiner.
Sometimes you need to compare differences in the data and identify the problematic data segments for analysis.
